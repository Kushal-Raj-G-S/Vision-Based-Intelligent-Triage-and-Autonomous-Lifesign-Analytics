# Era 7 — Going Public

`git init` was run for the first time this session (the project had never
been version-controlled). A `.gitignore` gap was found and fixed
(`**/venv/` was missing — only `.venv/`/`env/` were excluded, meaning the
entire virtual environment would have been committed).

A second, much larger gap was closed deliberately: dataset video files
(100GB+ across three datasets) were excluded from git entirely, while the
small evidence files (`manifest.csv`, every validation log, trace files)
were kept — verified via `git add -n .` dry run before ever actually
staging anything.

First commit: 74 files, ~3MB, zero raw dataset content. Pushed to
[github.com/Kushal-Raj-G-S/VITAL](https://github.com/Kushal-Raj-G-S/VITAL).

## Why this mattered beyond just "backing up code"

The project's dataset lives on a borrowed laptop that has to be returned to
its owner. The repository (README.md's Validation section + `CLAUDE.md` +
every log in `test/` + this `data/` folder) is what survives that laptop
being wiped — not the 100GB+ of video files, which were never the actual
asset. A dataset can be re-downloaded from the same free/public sources
documented in README.md; the specific bugs found, the specific fixes that
worked and didn't, and the specific real numbers measured cannot be
regenerated by re-downloading data — they only exist because someone traced
them, and that's what's actually preserved here.
